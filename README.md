# 好學小學堂 使用說明

一款打開一個 HTML 檔就能玩的問答闖關遊戲。玩家從幼稚園一路考到大學畢業；老師可以自己建立題庫，也可以請 AI 網站幫忙出題，再貼回遊戲裡匯入。

- 角色與場景都是用 Canva AI 生圖產生的原創可愛插圖；8-bit 音樂、題目也全部原創，不使用任何原作素材。
- 改版前用程式繪製像素圖的舊版，完整保留在「備份」資料夾裡（`備份/index.html` 可以直接打開玩）。
- 角色台詞已經預先配好語音（內嵌在檔案裡），自訂題目則用瀏覽器內建語音朗讀。
- 不需要網路、不需要安裝，複製到隨身碟或上傳到任何網頁空間都能玩。

---

## 一、開始玩

1. 用 **Chrome** 或 **Edge** 開啟 `好學小學堂○○.html`（直接雙擊即可）。iPad 用 Safari、Chromebook 用 Chrome 也可以。
2. 點一下畫面（「PRESS START」）開始。瀏覽器規定要先點一下才能播放聲音，所以第一下也是打開聲音。
3. 選擇模式 → 選角色和題庫組合 → 開始！

打包好的遊戲檔名稱是「好學小學堂」＋第一個題庫的名稱＋版本（學生版／教師版），例如「題庫」資料夾裡第一個題庫叫「六年級自然：單元3」，就會產生 `好學小學堂六年級自然：單元3（學生版）.html` 或 `好學小學堂六年級自然：單元3（教師版）.html`（本說明以下都寫成 `好學小學堂○○.html`）。

打包好的 `好學小學堂○○.html` **只會有打包前放在「題庫」資料夾裡的題庫**（做法見「五、把題庫打包進 HTML」），學生看不到其他題庫。

程式另外內建 6 份範例題庫（國語、數學、自然、社會、生活常識、台灣在地文化，各 30 題，共 180 題），預設**不會**打包進去；想讓學生也能玩範例題庫，打包時改用 `node tools/build.js --with-samples`。

### 操作方式

| 動作 | 滑鼠 / 觸控 | 鍵盤 |
| --- | --- | --- |
| 四選一、看圖題 | 點作業簿 | 1、2、3、4 |
| 是非題 | 點 ○ 或 ✕ | O / 1 是對，X / 2 是錯 |
| 排序題 | 依序點選項，點「重來」重排 | 1–6 依序按，Backspace 重來 |
| 數字題 | 螢幕數字鍵盤 | 數字鍵、小數點、`-`、Backspace、Enter |
| 下一題 | 點「下一題 ▶」 | Enter 或空白鍵 |
| 跳過校長致詞 | 點畫面 | 任意鍵 |
| 教室搶答 | 點螢幕四角的隊伍按鈕 | Q、P、Z、M（四隊） |

## 二、四種遊戲模式

### 1. 升學大冒險（主線）

| 學級 | 題數 | 每題秒數 | 及格線 | 出題難度 | 特色 |
| --- | --- | --- | --- | --- | --- |
| 幼稚園 | 5 | 15 | 60 | 1 | 教學關，有操作提示 |
| 國小 | 8 | 15 | 60 | 1–2 | 解鎖福利社 |
| 國中 | 10 | 12 | 60 | 2–3 | 隨機校園事件 |
| 高中 | 10 | 12 | 70 | 3–4 | 最後一題「聯考加分題」分數加倍 |
| 大學 | 12 | 10 | 70 | 4–5 | 王校長主持「畢業口試」 |

- **考卷分數**＝答對題數 ÷ 總題數 × 100，用來判斷及不及格。
- **排行榜分數**：答對一題 100 分＋剩餘秒數 × 10；連對 3 題起 ×1.2、5 題起 ×1.5、10 題起 ×2。
- 不及格會**留級**，用新題目重考一次；再不及格就**退學**，可以「投幣接關」再試一次。
- 畢業後頒發**畢業證書**，可以輸入名字登上排行榜、或按「列印證書」。
- 題數、秒數、及格線可以在「設定」頁修改。

**福利社道具**（答對賺學分幣，每次升級後可以買，每種最多帶 2 個；第一次進店送一個沙漏）

| 道具 | 效果 | 價格 |
| --- | --- | --- |
| 🔍 放大鏡 | 刪掉兩個錯誤選項（四選一、看圖題） | 30 |
| 🙋 求救同學 | 顯示全班投票比例（不一定對） | 20 |
| ⏳ 沙漏 | 這一題加 10 秒 | 15 |
| 🔄 換題卡 | 換一題新的 | 25 |
| 🧧 平安符 | 答錯時自動發動，這題不算錯 | 50 |

**隨機校園事件**（國中起）：突然抽考（秒數減半、學分幣加倍）、颱風假（直接算答對）、午餐時間（阿姨送道具）、黑板擦不乾淨（題目慢慢浮現）。

### 2. 社會大學（大人模式）

從實習生開始，答對加薪、答錯扣薪 8,000 元，依序升為專員、課長、經理、總經理、董事長；薪水歸零就被資遣。適合搭配「懷舊社會大學」組合。

### 3. 教室搶答（分組對戰）

1. 選 2–4 隊、輸入隊名、選題庫組合、題數、難度、搶到後的作答秒數。
2. 老師出題後，各隊按 **Q／P／Z／M** 或點螢幕四角搶答，只有最先按的隊伍拿到作答權。
3. 搶到的隊伍說出答案，由老師在電腦上點選。答錯就把機會讓給其他隊。
4. 上方有「公布答案」「跳題 / 下一題」「結束」，每隊下方有「加分」「扣分」。
5. 結束後顯示頒獎台。

### 4. 自由練習

選一份題庫（可指定難度），沒有時間限制，每題都會顯示詳解。結束後列出錯題，可以「只重練錯題」。

## 三、題庫系統

題庫分兩層：

- **題庫**：一組題目，例如「五年級自然第一單元」。
- **題庫組合**：一場遊戲要從哪些題庫、用什麼比例出題，例如「自然 U1 40%、自然 U2 30%、數學 U3 30%」。開始遊戲前選組合，就能一鍵切換今天複習的範圍。

在主選單按 **「📚 題庫管理」** 進入，有六個分頁：

| 分頁 | 功能 |
| --- | --- |
| 📚 題庫 | 題庫卡片（顯示各難度題數）、新增／編輯／刪除題目、「試玩」單一題、匯出 CSV 或 JSON、「還原內建題庫」（還原成這個檔案打包時的題庫） |
| 🧩 題庫組合 | 建立組合、設定比重；會提醒哪個學級題目不足 |
| 📥 匯入／匯出 | 拖曳 Excel／CSV／JSON 檔、貼上文字、下載範本、匯出全部備份 |
| 🤖 AI 出題 | 填年級、科目、單元，產生可以直接貼到 AI 網站的提示詞 |
| 🎙 錄音室 | 用麥克風錄下自己的台詞，取代預設語音 |
| 🔒 老師密碼 | 設定四位數密碼，學生就進不了題庫管理 |

### 題型與答案寫法

| 題型 | 中文名稱 | 選項 | 答案怎麼填 |
| --- | --- | --- | --- |
| `choice` | 四選一 | 剛好 4 個 | 正確選項的編號 1–4（也接受 A–D 或選項文字） |
| `truefalse` | 是非 | 不用 | `O`（對）或 `X`（錯）；也接受 ○、✕、對、錯、true、false |
| `order` | 排序 | 2–6 個 | 例如 `3,1,4,2`；**如果選項本來就照正確順序寫，答案可以留空或填 `1,2,3,4`**，遊戲會自動打亂 |
| `image` | 看圖 | 剛好 4 個 | 同四選一，另外要填「圖片」欄（`https://` 網址，或在編輯畫面上傳圖片） |
| `number` | 數字 | 不用 | 一個數字，例如 `144`、`0.75`、`-3` |

其他欄位：**難度**（必填 1–5）、**科目**（結算時算各科成績）、**詳解**（答題後顯示在黑板上）。

題目建議 40 字以內，黑板才放得下。

### 匯入方式 1：Excel／CSV

在「匯入／匯出」按「下載 Excel／CSV 範本」，用 Excel 開啟後照格式填寫：

```csv
題型,題目,選項1,選項2,選項3,選項4,答案,難度,科目,詳解,圖片
四選一,台灣最高的山是？,玉山,雪山,合歡山,阿里山,1,1,社會,玉山主峰約 3952 公尺,
是非,鯨魚是魚類。,,,,,X,1,自然,鯨魚是哺乳類,
數字,12 × 12 = ?,,,,,144,2,數學,,
排序,把數字由小到大排好,9,2,7,4,"2,4,3,1",2,數學,2→4→7→9,
```

- **一張工作表就是一份題庫，工作表名稱就是題庫名稱**，所以一個 `.xlsx` 可以一次匯入好幾份題庫。
- 可以直接拖入 `.xlsx`；也可以存成 CSV 再匯入。舊版 `.xls` 請先另存為 `.xlsx`。
- 也可以在 Excel 裡選取整個表格（含標題列）複製，直接貼到「貼上文字」框。
- 匯入前會先預覽；有問題的列會標紅色並說明原因（例如「第 12 列答案「7」不在 1–4」），只會匯入沒問題的題目。
- 預設會「同時建立只含這份題庫的組合」，匯入後馬上就能選來玩。

### 匯入方式 2：JSON

```json
{
  "bankId": "sci-5a-u1",
  "name": "五年級自然：太陽與天氣",
  "author": "王老師",
  "questions": [
    { "type": "choice", "question": "下面哪一種雲最容易帶來雷陣雨？",
      "options": ["卷雲", "積雨雲", "層雲", "高積雲"], "answer": 2,
      "difficulty": 2, "subject": "自然", "explain": "積雨雲又高又厚，常帶來雷電和大雨。" }
  ]
}
```

也可以是好幾份題庫組成的陣列 `[ {...}, {...} ]`。`bankId` 可省略；若和現有題庫相同，匯入時會詢問是否覆蓋。

### 匯入方式 3：用 AI 網站出題（推薦）

1. 到「題庫管理 → 🤖 AI 出題」，填好年級、科目、單元、題數、題型，按「📋 複製提示詞」。（也可以直接使用下一節的範例提示詞。）
2. 打開 ChatGPT、Gemini、Claude、Copilot 等任一 AI 網站，貼上提示詞送出。
3. AI 回覆後，把回覆**整段複製**（前後有說明文字或 ``` 符號都沒關係，遊戲會自動抓出題目）。
4. 回到「📥 匯入／匯出」，貼到「或貼上文字」框，按「檢查並預覽」→「匯入」。
5. **請老師一定要看一遍預覽表格**：AI 偶爾會出錯（答案錯、題目有爭議），可以在「📚 題庫 → 編輯」修改或刪除，或按「試玩」實際玩一次。

## 四、AI 出題提示詞範例

把 `【 】` 裡的內容換成你要的，整段複製到 AI 網站即可。

### 範例 1：通用版（輸出 JSON，最推薦）

```text
你是一位很會出題的台灣【國小高年級】【自然】老師。請幫我為「問答闖關遊戲」出一份題庫。

【主題／單元】【五年級自然：太陽與天氣】
【題數】30 題
【難度】1（最簡單）到 5（最難），每個難度的題數盡量平均
【題型】以四選一為主（約七成），其餘平均分給：是非題、排序題、數字題（答案是一個數字）

出題規則：
1. 一律使用繁體中文與台灣用語。
2. 題目 40 字以內，選項 15 字以內，因為要寫在黑板上。
3. 內容必須正確、適合【國小高年級】，答案只能有一個，不要出有爭議的題目。
4. 每題都要有一句 30 字以內的詳解，說明為什麼。
5. 四選一的正確答案位置要平均分散在 1、2、3、4。

題庫請用下面格式的 JSON，全部放在「同一個」程式碼區塊中，區塊裡只能有 JSON（知識點清單等說明請寫在程式碼區塊外面）：
{
  "name": "【五年級自然：太陽與天氣】",
  "author": "AI 出題",
  "questions": [
    {"type": "choice", "question": "台灣最高的山是？", "options": ["雪山", "玉山", "合歡山", "阿里山"], "answer": 2, "difficulty": 1, "subject": "【自然】", "explain": "玉山主峰約 3952 公尺。"},
    {"type": "truefalse", "question": "鯨魚是魚類。", "answer": "X", "difficulty": 1, "subject": "【自然】", "explain": "鯨魚是哺乳類，用肺呼吸。"},
    {"type": "order", "question": "依照青蛙的成長順序排好", "options": ["卵", "蝌蚪", "長出腳的蝌蚪", "青蛙"], "answer": "1,2,3,4", "difficulty": 2, "subject": "【自然】", "explain": "青蛙會經過變態才長大。"},
    {"type": "number", "question": "12 × 12 = ?", "answer": 144, "difficulty": 2, "subject": "【自然】", "explain": "12 個 12 是 144。"}
  ]
}

欄位說明：
- type：choice（四選一）、truefalse（是非）、order（排序）、number（數字）
- choice：options 一定要 4 個，answer 填正確選項的編號 1～4
- truefalse：不用 options，answer 填 "O"（對）或 "X"（錯）
- order：options 依「正確順序」寫 2～6 個，answer 填 "1,2,3,4"（遊戲會自動打亂）
- number：不用 options，answer 只填數字
- difficulty：1～5 的整數
（上面四題只是格式範例，請不要放進題庫）
```

### 範例 2：依照上傳的課文或講義出題（分析知識點、多種思考層次）

遊戲「🤖 AI 出題」頁的「參考資料」欄**已經預先填好**下面這段，複製提示詞後，在 AI 網站**一起上傳課文、講義或學習單的檔案**（PDF、Word、圖片都可以）再送出即可。也可以自己把這段加在範例 1 的【題型】那一行後面：

```text
【出題依據與要求】
請以我上傳的文件（課文、講義或學習單）作為出題範圍，依照下面步驟出題：
1. 先仔細閱讀文件，條列出文件中所有的知識點，並標出哪些是學生必須學會的核心概念。
2. 依照核心知識點出題，每個核心知識點至少出 1 題，越重要的知識點出越多題；不要出文件裡沒有教的內容。
3. 不要只考背誦，題目要涵蓋不同的思考層次：
   ・記憶：名詞、事實、定義
   ・理解：用自己的話解釋、比較異同、找出原因
   ・應用：放進生活情境、計算、解決問題
   ・分析：推理判斷、找出因果關係、辨認錯誤說法
4. 上面指定的每一種題型都要用到，難度 1～5 平均分配，應用和分析的題目放在難度 3～5。
5. 錯誤選項要合理、是學生常見的迷思，不要一眼就能看出答案。
6. 請先在程式碼區塊外面列出知識點清單，再輸出題庫。
```

- AI 會先列出知識點清單，再給題庫。整段回覆直接複製貼回遊戲就好，匯入時只會讀取程式碼區塊裡的題目，知識點清單不影響匯入。
- 沒有檔案可以上傳時，把這段換成課文文字（直接貼在「參考資料」欄），AI 就會依照貼上的內容出題。
- 有些免費版 AI 不能上傳檔案，這時請改用貼上文字的方式。

### 範例 3：輸出 CSV（想先貼到 Excel 修改的老師）

```text
你是一位很會出題的台灣【國中】【數學】老師。請幫我為「問答闖關遊戲」出一份題庫。

【主題／單元】【一元一次方程式】
【題數】20 題
【難度】1（最簡單）到 5（最難），每個難度的題數盡量平均
【題型】以四選一為主（約七成），其餘是是非題和數字題

出題規則：
1. 一律使用繁體中文與台灣用語。
2. 題目 40 字以內，選項 15 字以內。
3. 內容必須正確、答案只能有一個。
4. 每題都要有一句 30 字以內的詳解。
5. 四選一的正確答案位置要平均分散在 1、2、3、4。

題庫請用 CSV 格式，全部放在「同一個」程式碼區塊中，區塊裡只能有 CSV（說明文字請寫在程式碼區塊外面）。第一列是標題列：
題型,題目,選項1,選項2,選項3,選項4,答案,難度,科目,詳解

欄位填法：
- 題型：四選一、是非、排序、數字 其中一個
- 四選一：選項1～4 都要填，答案填正確選項的編號 1～4
- 是非：選項留空，答案填 O（對）或 X（錯）
- 排序：選項1～4 依「正確順序」填寫，答案填 1,2,3,4
- 數字：選項留空，答案只填阿拉伯數字
- 難度：1～5；科目：填「【數學】」
- 如果某一格裡有逗號，整格要用英文雙引號包起來

範例：
題型,題目,選項1,選項2,選項3,選項4,答案,難度,科目,詳解
四選一,台灣最高的山是？,雪山,玉山,合歡山,阿里山,2,1,社會,玉山主峰約 3952 公尺
是非,鯨魚是魚類。,,,,,X,1,自然,鯨魚是哺乳類
數字,12 × 12 = ?,,,,,144,2,數學,12 個 12 是 144
```

AI 回覆後，可以直接貼進遊戲匯入；或貼到 Excel（資料 → 從文字／CSV）修改後存成 `.xlsx` 再拖進遊戲。

### 範例 4：一次產生多份題庫

```text
請依照「範例 1」的規則和 JSON 格式，幫我出三份題庫，每份 20 題：
1.【五年級自然 第一單元：太陽與天氣】
2.【五年級自然 第二單元：植物的構造】
3.【五年級數學 第三單元：分數的加減】
請輸出成一個 JSON 陣列：[ {第一份}, {第二份}, {第三份} ]，每一份都要有自己的 "name" 和 "questions"。
```

匯入後會產生三份題庫，再到「🧩 題庫組合」把它們組合成「五年級期中複習」，設定比重 40／30／30。

### 範例 5：社會大學（大人模式）懷舊題

```text
你是一位熟悉台灣 1980～2000 年代生活的益智節目出題人。請依照「範例 1」的 JSON 格式，出 30 題適合大人的懷舊常識題，
主題包含：90 年代流行文化、台灣早期生活用品、柑仔店零食、校園回憶、老字號品牌、民俗節慶。
難度 1～5 平均分配，題型全部用四選一和是非題，科目填「懷舊」。
不要出有政治爭議或答案不確定的題目。
```

### 讓 AI 出題更好用的小技巧

- 題目太難或太簡單：在提示詞加上「難度 1 是國小三年級程度，難度 5 是國小六年級資優班程度」。
- 想要更多變化：加上「題目不要都用『下列何者』開頭，多用生活情境出題」。
- 題數很多（例如 100 題）時，AI 可能會中途停住，請分成好幾次、每次 20～30 題。
- AI 出的題目**一定要老師檢查過**再給學生玩。

## 五、把題庫打包進 HTML：從 AI 出題到產生遊戲檔的完整流程

在遊戲裡匯入的題庫，只存在「那一台電腦的那個瀏覽器」裡。如果要把題庫發給全班、其他老師，或放上網站，最好的做法是**把題庫打包進 `好學小學堂○○.html`**：任何電腦打開這個檔案，題庫和組合就已經在裡面了。

### 流程總覽

```
① 準備工具（只做一次）
      ↓
② 複製 AI 出題提示詞 → 貼到 AI 網站 → 拿到題目
      ↓
③ 把題目存成檔案，放進「題庫」資料夾
      ↓
④（選用）用「組合.json」設定題庫組合
      ↓
⑤ 雙擊「打包.bat」→ 產生新的 好學小學堂○○.html
      ↓
⑥ 打開新的 好學小學堂○○.html 檢查、試玩
      ↓
⑦ 把 好學小學堂○○.html 發給學生或放上網站
```

### 資料夾長這樣

```
0民國教育委員會-題庫遊戲/
├─ 好學小學堂○○.html  ← 打包產生的遊戲檔（○○ 是第一個題庫名稱，同名會被覆蓋成最新版）
├─ 打包.bat             ← 雙擊就打包（Windows）
├─ 題庫/                ← 把題庫檔放在這裡
│   ├─ _五年級自然.json       ← 範例：JSON 格式題庫
│   ├─ _五年級數學-分數.csv   ← 範例：CSV 格式題庫
│   └─ _組合.json             ← 範例：題庫組合設定
├─ src/                 ← 遊戲程式（一般不用動）
└─ tools/               ← 打包程式和語音檔（一般不用動）
```

> 檔名或資料夾名稱開頭是 `_`（底線）的**不會**被打包。範例檔都有底線，所以預設不會出現在遊戲裡。想用範例試試看，把檔名開頭的 `_` 刪掉再打包即可；想暫時停用某份題庫（或某個子資料夾），也只要在名稱前面加上 `_`。

### 學生會看到哪些題庫？（檔案 vs. 子資料夾）

學生在遊戲裡選的是「題庫組合」。「題庫」資料夾的擺法決定會產生哪些組合：

| 放法 | 學生看到的選項 |
| --- | --- |
| 檔案**直接**放在「題庫」資料夾 | 每個檔案各一個選項，名稱就是題庫名稱 |
| 檔案放在「題庫」裡的**子資料夾** | 整個子資料夾**只有一個**選項，名稱就是資料夾名稱；出題時從資料夾裡的每個檔案**平均**抽題 |

例如這樣擺：

```
題庫/
├─ 合併題庫/        ← 子資料夾
│   ├─ A.csv
│   └─ B.json
└─ C.csv
```

打包後，學生只會看到**兩個**選項：

- **合併題庫**：題目來自 A 和 B，兩份題庫各出一半
- **C**：題目全部來自 C

注意事項：

- 子資料夾只能有**一層**，子資料夾裡再開資料夾不會被讀取（打包時會提醒）。
- 子資料夾裡的 A、B 不會各自出現在「題庫組合」選單；但老師在「題庫管理」和「自由練習」仍然看得到 A、B 兩份題庫，可以單獨練習。
- 想要 A、B 不是平均、而是自訂比例（例如 A 七成、B 三成），請改用步驟 4 的 `組合.json`。
- 打包好的遊戲**只有「題庫」資料夾裡的題庫**，內建的 180 題範例題庫預設不會出現（想加入範例請見步驟 5 的 `--with-samples`）。

---

### 步驟 1：準備工具（只要做一次）

1. 到 <https://nodejs.org> 下載 **LTS 版**的 Windows 安裝檔（`.msi`），一路按「下一步」安裝完成。
2. 確認安裝成功：按開始鍵輸入 `PowerShell` 打開，輸入下面的指令按 Enter，出現 `v20.x.x` 之類的版本號就代表成功。

   ```powershell
   node --version
   ```

3. 打包**不需要網路**，也不需要 Python 或 ffmpeg（那些只有重新產生角色語音時才用得到）。

Mac 也可以：安裝 Node.js 後打開「終端機」，用 `cd` 進入遊戲資料夾，執行 `node tools/build.js`（`打包.bat` 只能在 Windows 使用）。

---

### 步驟 2：用 AI 產生題目

1. **取得提示詞**，兩種方式擇一：
   - 打開**教師版**的 `好學小學堂○○.html`（打包時選 N）→「📚 題庫管理」→「🤖 AI 出題」，填年級、科目、單元、題數、題型，按「📋 複製提示詞」。「參考資料」欄已預填「依上傳文件分析知識點、出多種思考層次題目」的要求，在 AI 網站送出時一起上傳課文或講義檔即可（見「四、範例 2」）；沒有檔案時，改把課文文字貼進「參考資料」。
   - 或直接複製上面「四、AI 出題提示詞範例」的範例，把 `【 】` 裡的內容換掉。
2. **貼到 AI 網站**：打開 ChatGPT、Gemini、Claude、Copilot 等，貼上提示詞送出。
3. **請 AI 自我檢查（建議）**：AI 回覆後，再送出這句：

   ```text
   請逐題檢查上面每一題的答案是否正確、是否只有一個正確答案，把有問題的題目修正後，用同樣的格式重新輸出完整的題庫。
   ```

4. **題數多時分批**：一次 20～30 題最穩定。如果 AI 輸出到一半停住，回覆「繼續」，或分成好幾次、每次存成不同檔案。

---

### 步驟 3：把題目存成檔案，放進「題庫」資料夾

四種方法擇一，**最推薦方法 B**（先在遊戲裡檢查過）。

#### 方法 A：直接把 AI 的回覆存成檔案（最快）

1. 在 AI 網站按回覆下方的「複製」按鈕（或選取整段回覆按 `Ctrl + C`）。
2. 打開「記事本」，按 `Ctrl + V` 貼上。
3. 按「檔案 → 另存新檔」：
   - **存檔位置**：遊戲資料夾裡的「題庫」資料夾
   - **檔案名稱**：例如 `五年級自然-太陽與天氣.json`（AI 輸出 JSON 時）或 `五年級數學-分數.csv`（AI 輸出 CSV 時）
   - **存檔類型**：選「所有檔案 (\*.\*)」
   - **編碼**：選「**UTF-8**」
4. AI 回覆前後的說明文字（例如「好的，以下是題庫」）和 ``` 符號**不用刪**，打包時會自動略過。
5. 不小心存成 `.txt` 也沒關係，打包程式一樣會讀。

題庫名稱：JSON 用裡面的 `"name"`；CSV 用**檔名**（例如 `五年級數學-分數.csv` → 題庫名稱「五年級數學-分數」）。

#### 方法 B：先在遊戲裡檢查、修改，再匯出（最推薦）

1. 打開**教師版**的 `好學小學堂○○.html`（打包時選 N）→「📚 題庫管理」→「📥 匯入／匯出」，把 AI 的回覆貼到「或貼上文字」框，按「檢查並預覽」→「匯入」。有問題的題目會標紅色並說明原因。
2. 到「📚 題庫」分頁，在剛匯入的題庫按「編輯」：逐題看過、修改錯的地方、按「試玩」實際玩一次。
3. 在題庫卡片上按「**JSON**」，瀏覽器會下載一個 `.json` 檔。
4. 把下載的檔案**移到「題庫」資料夾**。

這種 JSON 檔裡有固定的 `bankId`。之後修改同一份題庫再匯出，用新檔案**覆蓋**舊檔案就好。

#### 方法 C：用 Excel 編輯

1. 在遊戲「📥 匯入／匯出」按「下載 Excel／CSV 範本」，或請 AI 用 CSV 格式出題（四、範例 3），用 Excel 打開編輯。
2. 按「檔案 → 另存新檔」，**存檔類型選「CSV UTF-8（逗號分隔）(\*.csv)」**，存到「題庫」資料夾。
3. 注意：
   - 打包程式**不會讀 `.xlsx`**，一定要另存成 CSV。
   - Excel 另存 CSV 時**只會存目前這一張工作表**。有好幾張工作表的話，要每一張各存一個 CSV。
   - 一定要選「**CSV UTF-8**」。選成一般的「CSV（逗號分隔）」中文會變亂碼，打包時會出現一大堆錯誤。

#### 方法 D：放入遊戲的「完整備份檔」

在遊戲「📥 匯入／匯出」按「匯出全部備份（JSON）」，把下載的備份檔放進「題庫」資料夾。這台電腦上的**所有題庫和組合**都會一起被打包；自己錄的聲音不會被打包。

#### 檔案規則整理

| 規則 | 說明 |
| --- | --- |
| 會被讀取的檔案 | `.json`、`.csv`、`.tsv`、`.txt` |
| 不會被讀取 | 名稱開頭是 `_` 的檔案或資料夾、Excel 檔（`.xlsx`、`.xls`）、第二層以下的資料夾 |
| 子資料夾 | 裡面的所有題庫合併成一個以資料夾為名的選項，平均出題（見上面「學生會看到哪些題庫？」） |
| 編碼 | 一律 **UTF-8** |
| 一個檔案放好幾份題庫 | JSON 可以用陣列：`[ {第一份}, {第二份} ]` |
| 特殊檔名 | `組合.json` 是題庫組合設定，不是題庫（見步驟 4） |

---

### 步驟 4（選用）：設定題庫組合

**不設定也可以玩**。打包時會自動建立：

- 直接放在「題庫」資料夾的每份題庫，各一個同名組合（例如「五年級數學-分數」）
- 每個子資料夾一個組合，名稱是資料夾名稱，裡面的題庫平均出題

想要自訂比例，例如「自然 60%、數學 40%」，就把 `題庫/_組合.json` 複製一份，改名為 **`組合.json`**（拿掉底線），用記事本打開修改：

```json
[
  { "name": "五年級期中複習", "banks": { "五年級自然：太陽與天氣": 60, "五年級數學-分數": 40 } },
  { "name": "自然數學平均",   "banks": ["sci-5a-u1", "五年級數學-分數"] }
]
```

- `name`：組合名稱，會出現在遊戲的「題庫組合」選單。
- `banks` 有兩種寫法：
  - `{ "題庫": 比重, ... }`：數字是出題比例（60、40 代表 60%、40%）
  - `[ "題庫", "題庫" ]`：平均分配
- 「題庫」可以填：**題庫名稱**（JSON 的 `name`）、**bankId**，或**檔名（不含副檔名）**。
- 名字打錯時，打包會停下來並告訴你哪一個找不到。

---

### 步驟 5：打包

**方法 1（最簡單）**：在遊戲資料夾裡**雙擊 `打包.bat`**。

**方法 2**：在遊戲資料夾空白處按住 `Shift` 再按右鍵 →「在這裡開啟 PowerShell 視窗」（或「在終端機中開啟」），輸入：

```powershell
node tools/build.js
```

成功時會看到類似這樣的訊息：

```
內建題庫：
  ・A（20 題）
  ・B（20 題）
  ・C（30 題）
題庫組合（學生在遊戲裡選的）：C、合併題庫（A＋B）

版本：學生版（已隱藏「題庫管理」）

✔ 好學小學堂C（學生版）.html 完成：2.84 MB，圖片 26 張，語音 60 句，題庫版本 263d19e3317d
```

「題庫組合」那一行就是學生會看到的選項；括號裡是合併進來的題庫。

**打包時會詢問要不要隱藏「題庫管理」**：

```
要隱藏「題庫管理」嗎？輸出給學生練習用建議隱藏。
  Y＝隱藏（學生版，直接按 Enter 也是）  N＝保留（教師版）：
```

| 版本 | 怎麼選 | 打包出來的遊戲 |
| --- | --- | --- |
| 學生版 | 輸入 `Y` 或直接按 Enter | 主選單**沒有「📚 題庫管理」**，學生只能練習、闖關，不能看答案、改題目、匯入匯出或用 AI 出題 |
| 教師版 | 輸入 `N` | 保留「📚 題庫管理」，可以檢查題目、試玩、用 AI 出題、錄音 |

不想每次被詢問，可以直接指定：

```powershell
node tools/build.js --student
```

```powershell
node tools/build.js --teacher
```

`--student`、`--teacher` 都可以和 `--with-samples` 一起用。

**檔名規則**：遊戲檔會叫「好學小學堂」＋學生在「題庫組合」選單裡看到的**第一個**題庫名稱，例如 `好學小學堂C（學生版）.html`、`好學小學堂合併題庫（教師版）.html`。檔名不能用的符號（`\ / : * ? " < > |`）會換成 `_`。檔名最後會標上「（學生版）」或「（教師版）」，所以兩種版本可以同時存在、不會互相覆蓋；同一種版本再打包一次，才會覆蓋上一次的檔案。

看懂訊息：

| 訊息 | 意思 | 怎麼辦 |
| --- | --- | --- |
| `✔ 好學小學堂○○.html 完成` | 成功，遊戲檔已產生（同名的舊檔會被覆蓋） | 進行步驟 6 |
| `⚠ … 第 6 列：答案「9」不在 1–4（這題略過）` | 這一題格式有問題，**沒有**被打包，其他題目正常 | 打開那個檔案修正那一列，再打包一次 |
| `✘ 打包失敗：…` | 整個打包停止，遊戲檔**沒有**被改動 | 依照訊息修正後再打包一次 |

打包好的遊戲**只會有「題庫」資料夾裡的題庫**，看不到內建的 180 題範例題庫。「題庫」資料夾裡沒有任何題庫時，打包會停下來提醒你。

如果**也想把範例題庫一起打包**給學生玩，改用：

```powershell
node tools/build.js --with-samples
```

---

### 步驟 6：檢查新的 好學小學堂○○.html

1. 打開新的 `好學小學堂○○.html`。
2. 進「📚 題庫管理 →📚 題庫」，確認新題庫在裡面、各難度的題數正確。
3. 用「試玩」或「自由練習」實際玩幾題。
4. 回選單 →「升學大冒險」，在「題庫組合」下拉選單確認組合都在。如果出現「⚠ 題目不足」，代表某個學級可用的題目太少，會重複出題，可以補題目或到「設定」減少題數。

---

### 步驟 7：發布給學生

- **只需要 `好學小學堂○○.html` 這一個檔案**。複製到隨身碟、雲端硬碟、學校電腦，或上傳到網站都可以。
- 學生的電腦**以前玩過舊版**也沒關係：打開新版時，內建題庫會**自動更新**成新版內容。
- 老師、學生自己在遊戲裡建立的題庫、排行榜、錄音都**不受影響**。

---

### 之後要更新題庫

修改「題庫」資料夾裡的檔案 → 再打包一次 → 發布新的 `好學小學堂○○.html`。

注意事項：

- **要改內建題庫，請改「題庫」資料夾裡的檔案**。在遊戲裡直接修改內建題庫，下次打開新版 `好學小學堂○○.html` 時會被檔案的內容蓋掉。
- **不要隨便改檔名或子資料夾名稱**：CSV 題庫用「子資料夾名稱＋檔名」當作身分，改了會被當成另一份新題庫，舊電腦上會同時出現新舊兩份。JSON 題庫則是用 `bankId` 當身分。
- 已經玩過舊版的電腦，打開新版 `好學小學堂○○.html` 時會**自動整理**：從「題庫」資料夾刪掉的題庫、以前打包進去的範例題庫，都會自動移除，畫面上只剩這次打包的題庫。老師自己在遊戲裡（題庫管理）建立或匯入的題庫不會被刪。

### 用教師版增修題庫後，再打包

**重要觀念：打包程式只讀「題庫」資料夾裡的檔案。**
在教師版「📚 題庫管理」裡新增、修改、刪除的題目，只存在**那一台電腦的那個瀏覽器**裡，打包程式讀不到，所以**不會**自動打包進新的 HTML。要把增修的內容打包進去，必須先把題庫匯出成檔案、放回「題庫」資料夾。

```
教師版裡增修題目、試玩
      ↓
在題庫卡片按「JSON」匯出
      ↓
用匯出的 JSON「取代」題庫資料夾裡原本的那份檔案
      ↓
重新打包（學生版／教師版）
```

**步驟：**

1. 打開教師版 `好學小學堂○○（教師版）.html` →「📚 題庫管理」→「📚 題庫」。
2. 在要修改的題庫按「編輯」：新增、修改、刪除題目，並用「試玩」確認沒問題。
3. 改好後，在這份題庫的卡片上按「**JSON**」，瀏覽器會下載一個 `題庫名稱.json`。
4. 把下載的 JSON 放進「題庫」資料夾，**取代原本那份檔案**：
   - 原本是直接放在「題庫」裡的 `C.csv` → 把 JSON 放進「題庫」，並把原本的 `C.csv` **刪掉**（或在檔名前加 `_` 暫時停用）。
   - 原本放在子資料夾裡（例如 `合體01/A.csv`）→ JSON 要放回**同一個子資料夾** `合體01/`，再刪掉原本的 `A.csv`，合併題庫才會照舊。
   - 原本就是 JSON → 直接用新的 JSON 覆蓋舊檔。
5. 重新打包（雙擊 `打包.bat`，選學生版或教師版），把新的 HTML 發給學生。

**為什麼一定要「取代」，不能新舊並存？**
匯出的 JSON 和原本的檔案是同一份題庫（同一個 `bankId`）。兩個同時放在「題庫」資料夾，打包時會出現「有兩份題庫的 bankId 一樣」並停止。

**為什麼用 JSON，不用 CSV？**
JSON 會完整保留題目編號、題庫 ID 和上傳的圖片；CSV 不會保留內嵌圖片，重新匯入時也可能變成另一份題庫。

**不要用「匯出全部備份」來更新題庫**
備份檔裡也包含原本打包進去的所有題庫，和資料夾裡的檔案放在一起一樣會重複。要更新哪一份題庫，就單獨匯出那一份。

**改完要馬上匯出**
在教師版裡修改**打包進去的題庫**後，如果之後打開了**重新打包過的新版 HTML**，這些題庫會自動還原成「題庫」資料夾裡的內容，瀏覽器裡沒匯出的修改就會**不見**。（在教師版裡**自己新增**的題庫不會被還原，但一樣不會被打包，記得也要匯出。）

**建議的工作習慣**：把「題庫」資料夾裡的檔案當作**正本**。在教師版改好 → 馬上匯出 JSON 取代正本 → 再打包，就不會遺失任何修改。

### 打包常見問題

**Q：雙擊 `打包.bat` 出現「Node.js not found」？**
還沒安裝 Node.js，或安裝後沒有重新開機或重新開視窗。請照步驟 1 安裝後再試一次。

**Q：每一列都出現「題型看不懂」，或中文變成亂碼？**
檔案不是 UTF-8 編碼。用記事本打開後「另存新檔」，編碼選「UTF-8」；Excel 則要選「CSV UTF-8（逗號分隔）」。

**Q：出現「JSON 格式有錯」？**
通常是 AI 的回覆被截斷（題數太多），結尾少了 `]` 或 `}`。請 AI「繼續」或分批出題。也可以先把內容貼到遊戲的「📥 匯入／匯出」檢查，比較容易找到問題。

**Q：出現「有兩份題庫的 bankId 一樣」？**
兩個 JSON 檔裡的 `"bankId"` 相同，請把其中一個改成不同的英數字（例如 `sci-5a-u2`）。

**Q：打包成功了，但打開還是舊的題目？**
確認打開的是剛產生的那個 `好學小學堂○○.html`（看資料夾裡的修改時間）。若是放在網站上，請按 `Ctrl + F5` 強制重新整理。

**Q：可以只修改一題就重新打包嗎？**
可以。改完檔案存檔，再雙擊 `打包.bat` 就好，幾秒鐘就完成。

## 六、題庫組合、老師密碼、錄音室

- **題庫組合**：勾選要用的題庫，在「比重」填出題比例（例如 40、30、30；全部填 1 就是平均）。卡片下方會提醒哪個學級的題目不足。題目不夠時，遊戲會先從相鄰難度補，還是不夠才會重複出題。
- **老師密碼**：在「題庫管理 → 🔒 老師密碼」設定四位數密碼。忘記密碼時：按 `F12` 開啟開發者工具 → Console，輸入 `localStorage.removeItem('mg-settings')` 按 Enter（會一併還原音量等設定，題庫不受影響）。
- **錄音室**：每一句角色台詞都可以按「● 錄音」用麥克風重錄，按「■ 停止」存檔，重新整理後仍在。可以請班上同學來配音，學生會玩得更投入！第一次使用時瀏覽器會詢問是否允許使用麥克風。

## 七、設定

主選單或標題畫面右上角的「⚙ 設定」：

- 音樂、語音、音效三個音量滑桿（語音播放時背景音樂會自動變小）。
- **讀題**：用瀏覽器內建語音朗讀題目。設定頁會顯示「這台電腦有沒有中文語音」；沒有中文語音時只會顯示字幕，角色台詞仍有聲音。
- **大聲公模式**：語音音量加大，適合接喇叭。
- **大字模式**、**關閉閃爍特效**。
- 升學大冒險各學級的題數、秒數、及格線。

所有台詞都有字幕，關掉聲音也能完整遊玩。

## 八、備份與換電腦

題庫、組合、錄音都存在**這台電腦、這個瀏覽器**裡（IndexedDB），排行榜和設定存在 localStorage。

- 換電腦、換瀏覽器、清除瀏覽器資料之前，請到「📥 匯入／匯出」按 **「匯出全部備份（JSON）」**。
- 到新電腦打開遊戲，把備份檔拖進匯入框，按「還原這份備份」即可（錄音也會一起還原）。
- 要分享題庫給其他老師：在題庫卡片按「CSV」或「JSON」匯出單一題庫。

注意：同一個 `好學小學堂○○.html` 放在不同資料夾、或用不同瀏覽器開啟，會被視為不同的網站，資料不會互通，請用備份檔搬移。

## 九、常見問題

**Q：打開後沒有聲音？**
先點一下畫面（瀏覽器規定要先互動才能播放聲音），並檢查「設定」的音量和電腦音量。

**Q：讀題沒有聲音，但角色有說話？**
這台電腦的瀏覽器沒有中文語音。Windows 可到「設定 → 時間與語言 → 語音」新增「中文（台灣）」語音；或在設定頁關閉讀題。

**Q：選題庫組合時出現「題目不足」？**
代表某個學級可用的題目比需要的題數少，遊戲會重複出題。請匯入更多題目，或到設定頁減少題數。

**Q：可以放到網路上給學生在家玩嗎？**
可以，把 `好學小學堂○○.html` 上傳到任何網頁空間（例如 GitHub Pages、學校網站）。但每位學生的題庫存在自己的瀏覽器，建議照「五、把題庫打包進 HTML」把題庫打包進 好學小學堂○○.html，學生打開就有題目。

**Q：iPad 上字太小？**
到設定開啟「大字模式」，並把 iPad 轉成橫向。

### 更換或新增圖片

圖片檔名就是程式裡的名字，換圖只要同名覆蓋：

| 檔名 | 用在哪裡 |
| --- | --- |
| `teacher`、`aming`、`ying`、`qiang` | 林老師與三位玩家角色的普通表情 |
| `○○_happy`、`○○_sad` | 上面四個角色的開心（答對、升級）與難過（答錯、留級）表情 |
| `principal`、`aunt`、`bird`、`classmates` | 王校長（也當社會大學的董事長）、福利社阿姨、藍啚、背景同學一排 |
| `bg_title`、`bg_classroom`、`bg_kinder`、`bg_univ`、`bg_auditorium` | 標題、國小到高中教室、幼稚園、大學、期末考禮堂 |
| `bg_shop`、`bg_sunset`、`bg_graduation`、`bg_office`、`bg_bulletin` | 福利社、留級夕陽教室、畢業典禮、社會大學辦公室、選角公佈欄 |

1. 把新圖存成 PNG，放進 `tools/images/raw/`，用上表的檔名覆蓋。角色圖請用**純白背景、全身、置中**，處理程式會自動去背；背景圖建議 4:3。
2. 執行下面兩個指令（需要 Python 和 Pillow：`pip install pillow`）：

```powershell
python tools/process_images.py
```

```powershell
node tools/build.js
```

角色的表情圖可以只放普通版；沒有 `_happy`／`_sad` 時，遊戲會用普通圖加上跳動、星星、汗滴、眼淚等特效代替。

修改 `src/` 之後重新打包：

```powershell
node tools/build.js
```

修改 `src/lines.json` 的台詞後重新產生語音（需要 Python、`pip install edge-tts`、ffmpeg）：

```powershell
python tools/gen_voices.py --force
```

```powershell
node tools/build.js
```

### 美術與語音的來源

- **美術**：26 張角色與場景插圖用 Canva 的 AI 生圖產生（企劃書的方案 C：先用程式繪圖版本，再換成美術圖）。表情圖是以同一角色的普通圖當參考生成，所以長相一致。原圖另外存在你 Canva 帳號的設計「民國小學堂 遊戲素材」裡。黑板、鬧鐘、課桌、火焰、彩帶等小物件仍由程式繪製。AI 生成圖若要公開散布或商業使用，請先確認 Canva 的使用條款。
- **音樂與音效**：全部用 Web Audio API 即時合成。旋律為原創；畢業典禮使用公眾領域的蘇格蘭民謠〈Auld Lang Syne〉旋律，上下課鐘使用公眾領域的西敏寺鐘聲旋律。
- **角色語音**：女聲角色（林老師、小瑩、藍啚、福利社阿姨、同學們）使用 Microsoft Edge 的台灣中文神經語音（edge-tts）預先產生；男聲角色（王校長、阿明、胖仔強、董事長）因為產生當時線上男聲服務無法使用，改用 Windows 內建的台灣中文語音「Zhiwei」產生，再用 ffmpeg 調整音高與語速區分角色，所以音質比女聲角色稍差。這些語音若要公開散布或商業使用，請先自行確認微軟語音服務的使用條款；最保險的做法是用「錄音室」換成自己錄的聲音。
- **字型**：使用電腦內建的中文字型（微軟正黑體等）。若電腦有安裝圓體「jf open 粉圓」（SIL OFL 開源授權），遊戲會自動使用，和插圖風格更搭。
